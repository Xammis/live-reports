What agents cannot do yet

These are narrow gaps. HubSpot's normal screens still handle most of them.

Press the final API Send button

Agents can finish the draft. A person must publish, schedule, or send it inside HubSpot.

Send transactional emails by software

No automatic receipts, order updates, or one-recipient system messages through the API.

Create brand-new coded email templates

Agents can find and use existing templates, then edit the email built from them.

Enroll people into sales sequences

Agents can review sequences and enrollment history, but not start a new enrollment.

Run every marketing channel

Forms, social publishing, and ad-platform management still belong in HubSpot's UI or their own tools.

Bypass HubSpot permissions

Agents only see and change what the account, subscription, and approved scopes allow.

Important: Regular sending inside HubSpot still works. The lock applies to agents sending through the API.
