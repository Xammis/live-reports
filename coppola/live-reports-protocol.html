Xammis infrastructure · live delivery

Every report ends as a page people can actually open.

The agent cast now shares one publishing protocol: generate locally, sanitize carefully, file by author, push to GitHub Pages, and verify the public HTML before sending the link.

01GenerateCreate a complete, self-contained HTML report.
02SanitizeRemove credentials, private data, and unnecessary operational details.
03FilePlace the page beneath the authoring agent's folder.
04PublishCatalog, commit, and push the report to the main branch.
05VerifyWait until GitHub Pages serves the exact current HTML.

Delivery invariants

✓
Public HTTPS only

No local paths, attachments, blob links, or localhost URLs.

✓
Author owns the folder

The agent who creates the report determines its canonical path.

✓
Exact-content verification

Success waits for the live page to match the generated report.

https://xammis.github.io/live-reports/<agent>/<report>.html
Definition of done: a report is not ready when it exists on disk. It is ready when the remote user can open its verified web page.
