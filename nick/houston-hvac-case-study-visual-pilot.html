WordPress implementation notes

How this becomes reusable page content

Build as blocks

  • Impact decomposition block
  • Hybrid mix block
  • Before-and-after spend block
  • Operational change flow

Keep the meaning crawlable

  • Use real headings, paragraphs, lists, and tables
  • Use CSS for bars, chart shapes, spacing, and color
  • Add accessible labels to decorative chart elements
  • Keep corrected figures in one source field set
Content cleanup noticed during the pilot: The live case study opens with a logistics-company headline, nationwide footprint map, vendor-consolidation graphic, and logistics-manager quote. Those do not match the Houston HVAC story and should be replaced or removed during implementation.

Recommended page placement

  1. Place the impact decomposition after “The number that actually matters.”
  2. Place the hybrid mix after “What we changed, and what we did not.”
  3. Replace the image-based direct-fuel comparison with the semantic comparison table.
  4. Use the operational change flow before “What changed on the ground.”
  5. Keep the social assets outside the page body and use them for distribution.
