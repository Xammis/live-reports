04 · Dark surface test

Expanded capability, unchanged guardrails

This paragraph uses Base white because it sits on a dark Contrast background. Safety remains part of the operating model, not a decorative footnote.

Safe by default

Every call names the intended account and uses stable output for evidence.

  • Read-only mode for analysis
  • No tokens in chat
  • No fabricated source data

Permission-aware

Scope never guarantees access to every property, file, or customer.

  • Cloud APIs must be enabled
  • Folder sharing still applies
  • Ads needs separate setup

Human-controlled

High-impact or outbound operations stay behind explicit approval.

  • No unrequested email sending
  • No destructive operations
  • No silent scope expansion
