06

Guardrails that stay in place

Safe by default

  • Explicit Google account on every API call
  • Read-only mode for analysis
  • Stable JSON for evidence and calculations
  • No credentials or OAuth tokens in chat

Permission still matters

  • OAuth scope does not guarantee access to every property or file
  • Cloud APIs must be enabled
  • Ads needs customer/developer-token setup
  • Shared folders need correct editor permissions

Human approval remains

  • No email sending unless explicitly requested
  • No destructive operations without confirmation
  • No silent scope expansion
  • No fabricated data when a source is unavailable
